# ADR-0037: 단타 레버리지 사용 방안 (제안)

**Status:** Proposed (동동님 선택 대기, 상수 변경 없음)
**Date:** 2026-10-03
**Deciders:** account owner (동동), Claude Code session

## Context

동동님 요청(2026-10-03): 레버리지 기능을 적절하게 쓰고 싶다. 현재 상태를 코드에서 확인한 결과:

- **포지션 크기는 이미 손절 거리로 정한다.** `RiskEngine`이 "손절에 걸리면 자본의 0.5%를 잃는" 수량을
  계산하고(`risk_per_trade` 0.005), 명목가가 자본의 2배(`max_leverage` 2.0)를 넘으면 자른다
  (`configs/risk.json`, `risk/engine.py`). 즉 실효 레버리지 = 0.5% ÷ 손절 거리이고, ADR-0033 진단에서
  BTC 15분봉 진입 크기 중앙값이 자본의 약 0.7배였다.
- **거래소 레버리지 설정(증거금 방식·배율)은 백테스트에만 있다.** 백테스트는 격리 마진 3배를 가정하고
  청산을 시뮬레이션한다(`event_engine.FuturesTerms.margin_leverage`). 페이퍼·라이브 경로에는 증거금 방식이나
  배율을 거래소에 설정하는 코드도, 청산가 확인도 없다. 바이낸스 기본값(교차 마진·높은 배율)으로 주문이
  나가면 백테스트 가정과 달라진다.
- 리스크 엔진의 하루 손실 3%, 낙폭 15%, 연패 가드는 레버리지와 상관없이 그대로 적용된다.
- 펀딩비는 백테스트·페이퍼에서 거래마다 반영되고(최대 12시간 보유라 1~2회 정산), ADR-0036으로 원화
  순수익에도 들어간다.
- 사전등록 전이다(가장 이른 등록 2026-10-29). 레버리지·위험 값은 등록 때 고정되므로, 바꾸려면 지금
  정하는 게 맞다. 등록 후에는 새 id가 필요하다.

"건당 3%"는 가격 3% 움직임 기준이다. 레버리지 1배면 자본 3%, 0.7배면 약 2%가 된다. 레버리지를 올리면
수익과 손실이 같은 배수로 커지고 비용(수수료·스프레드)도 명목가에 비례해 커진다.

## 선택지

- **A. 현행 위험 유지 + 안전장치 (추천)**: 거래당 위험 0.5%, 실효 레버리지 상한 2배 그대로. 추가로
  (1) 페이퍼·라이브도 격리 마진, 거래소 배율 = 3배로 고정해 백테스트 가정과 맞추고, (2) 진입 전 청산가가
  손절가보다 최소 3배 멀리 있는지 확인해 아니면 진입 거절(`risk/leverage.py` 재사용), (3) 라이브 첫 주문 전
  거래소의 증거금 방식·배율이 설정값과 같은지 확인하고 다르면 거래 중단.
- **B. 공격적**: A의 안전장치 + 거래당 위험 1.0%, 상한 3배. 수익·손실이 약 2배. 하루 손실 한도(3%)에
  손절 3번이면 닿는다. 검증 전에는 근거 없는 상향이라 추천하지 않는다.

A를 고르면 `configs/risk.json` 값은 그대로이고 안전장치 코드만 추가한다. B를 고르면 `risk.json` 값이 바뀌어
`RiskConfig.version()`이 달라지고, 사전등록 시 그 값으로 고정된다. 어느 쪽이든 실제 성과(페이퍼 결과)를
보고 등록 전에 다시 조정할 수 있다.

## Decision

동동님 선택 후 확정한다. 확정 전까지 상수·리스크 코드는 바꾸지 않는다.

## Consequences (선택 전 준비분)

A·B 공통 안전장치의 계산 부분만 먼저 넣었다. 진입 경로에는 아직 연결하지 않았다(설정값·리스크 동작 변화 없음).

- `risk/margin_policy.py`: `MarginPolicy`(격리, 거래소 배율 3, 청산가 ≥ 손절 거리 3배),
  `liquidation_vs_stop_reason`(마진 등급표 없거나 입력 이상이면 거절), `margin_settings_mismatches`.
- `BinanceFuturesClient.symbol_config`: `/fapi/v1/symbolConfig` 읽기 전용 조회(증거금 방식·배율 확인용).
  거래소 설정을 바꾸는 호출은 넣지 않았다.
- 남은 일(선택 후): 페이퍼·라이브 진입 경로 연결. 페이퍼는 API 키 없이 마진 등급표를 받을 수 없어서, 등급표
  스냅샷을 설정 파일로 둘지 정해야 한다.
