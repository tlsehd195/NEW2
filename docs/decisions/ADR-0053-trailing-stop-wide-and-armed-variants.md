# ADR-0053: 추적 손절 변형: 넓게(4.5 ATR), 이익 난 뒤에만(1.5 ATR 활성)

**Status:** Accepted (2026-10-09 동동님 "진행": 두 변형을 선별로 비교)
**Date:** 2026-10-09
**Deciders:** account owner (동동), Claude Code session

## Context

- ADR-0052 첫 선별: 진입 직후부터 2.5 ATR로 따라가는 추적 손절은 끔보다 조금 나빴다(구간 평균 h16 -1.02% vs -0.96%,
  h48 -1.38% vs -1.22%). 일찍 털리고 다시 들어가 거래가 10~14% 늘었다.
- 동동님 의견: 벌고 있다가 되돌리더라도 이익은 확정되는 것이니 의미가 있다. 두 가지를 더 본다:
  (a) 간격을 넓힌다, (b) 이익이 어느 정도 난 뒤에만 따라가기 시작한다.

## Decision

1. 신호에 `trailing_activation`(가격이 진입가에서 유리한 쪽으로 이만큼 움직인 뒤에만 추적 시작)을 추가한다.
   없으면(기본) 지금과 같다. 백테스트(`event_engine.py`)와 모의투자(`paper/engine.py`) 둘 다 같은 조건을 쓴다.
   `trailing_distance` 없이는 둘 수 없다. 저장된 모의투자 상태에는 필드가 없어도 읽힌다(기본 None).
2. `IndicatorVote`에 `trail_activate_atr`(기본 None). 값이 있으면 id에 `a<값>`이 붙는다.
3. 선별 후보 4개(선별 전용, 사전등록 아님). 값은 결과를 보기 전에 정했다:
   - `..._t4.5_v1`: 진입부터 4.5 ATR 간격.
   - `..._t1.5a1.5_v1`: +1.5 ATR 이익이 난 뒤에 시작, 1.5 ATR 간격(시작 순간 손절선이 본전).
   - 각각 h16, h48.
4. ADR-0052와 같은 범위(BTCUSDT 15m, 2023-04-20~2024-06-18)로 선별해 같은 표로 비교한다.

## Consequences

- 모의투자 설정은 그대로. 켜려면 선별 결과 후 결선이 필요하다.
- 선별 후보 4개가 더 DSR 시도 수에 더해진다(누적 8).

## 선별 결과 (2026-10-09, GitHub Actions run 37893856043, 선별일 뿐 검증 아님)

ADR-0052와 같은 범위·같은 46폴드. 이전 4개와 합쳐 구간 평균 수익률:

| 지평 | 끔(고정 손절) | 2.5 ATR 추적 | 4.5 ATR 추적 | +1.5 ATR 뒤 시작(1.5 간격) |
|---|---|---|---|---|
| h16 | -0.96% (거래 454) | -1.02% (499) | **-0.90%** (456) | -0.98% (514) |
| h48 | -1.22% (460) | -1.38% (523) | -1.32% (476) | -1.51% (568) |

- 이긴 폴드: h16 17/14/17/16, h48 11/8/12/8 (같은 열 순서). PBO 0.47, DSR 시도 수 79, 모든 후보 DSR≈0.
- 넓은 추적(4.5)은 끔과 거의 같다(h16 +0.06%p, h48 -0.10%p). 차이가 작아 우연과 구분되지 않는다.
- 이익 난 뒤에 시작하는 방식이 두 지평 모두 가장 나빴고 거래 수가 가장 많았다(본전에서 청산된 뒤 다시 진입).
- 결론: 어떤 추적 손절도 끔보다 뚜렷이 낫지 않다. 기본값은 끔. 여덟 후보 모두 손실이라 결선 후보 없음.
