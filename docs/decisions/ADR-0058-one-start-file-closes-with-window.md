# ADR-0058: 시작 파일 하나, 창을 닫으면 전부 꺼짐

**Status:** Accepted
**Date:** 2026-10-10
**Deciders:** account owner, Claude Code session

## Context

ADR-0057의 창 없는 시작은 시작·정지·상태 파일이 따로 있었고, 옛 방식(`start-dashboard-next.bat`, 검은 창 3개)도 남아 있었다.
사용자는 "그냥 켜는 것 하나만 두고, 프로그램을 끄면 같이 꺼지게" 해 달라고 했다. 앞서 정했던 "창을 닫아도 모의투자는 계속 돌기"는
사용자가 직접 바꾼 것이다.

## Decision

- 사용자용 실행 파일은 `start-new2.vbs` 하나다. `stop-new2.vbs`, `status-new2.bat`, `start-dashboard-next.bat`은 지웠다
  (`scripts/launcher.py stop|status`는 개발용으로 남는다).
- 시작하면 모의투자·자료 서버·화면 서버를 뒤에서 켜고, 전용 프로필(`var/launcher/browser-profile`)로 Edge(없으면 Chrome) 앱 창을 연다.
  전용 프로필이라 브라우저 프로세스가 창과 함께 끝나므로, 런처는 그것을 기다렸다가 창이 닫히면 ADR-0057의 정지 방식(STOP 파일로
  모의투자가 상태를 저장하고 끝남, 30초 안에 안 끝나면 강제 종료)으로 전부 끈다.
- 런처는 `var/launcher/launcher.lock`을 쥔다. 이미 런처가 있으면 새 창만 하나 더 연다(중복 실행 없음).
- 비정상 종료(런처가 죽음, PC 꺼짐)로 남은 것은 다음 시작 때 먼저 정리한다: 기록된 프로세스를 정리하고 모의투자는 STOP으로 닫은 뒤 새로 켠다.
- Edge/Chrome이 없으면 기본 브라우저로 열고 안내창을 띄운다. 이 경우 창이 닫혔는지 알 수 없어 자동 종료는 되지 않는다(다음 시작 때 정리).

## Consequences

- 창을 닫으면 모의투자가 멈춘다. 그동안 포지션의 손절·청산 판단이 돌지 않는다. 다시 켜면 저장된 상태에서 이어가고 복구 절차(대조)를 거친다.
- 화면을 보는 동안만 모의투자를 돌리는 방식이 되어, 24시간 돌리려면 창을 열어 둬야 한다.
- 정지 기록(`var/logs/launcher.log`)에 창 닫힘, 정리, 강제 종료가 남는다.
- Windows에서는 직접 시험하지 못했다(Linux에서 시작, 두 번째 시작, 창 닫힘, 런처 강제 종료 후 정리를 확인).
