# ADR-0064: taker flow 15분 후보 전략(FlowVote)

**Status:** Accepted (후보 보존, 선별 결과 음성: 결선 후보 없음)
**Date:** 2026-10-10
**Deciders:** account owner (조합 방식은 Claude에게 위임), Claude Code session

## Context

선행 신호 논문 조사(research/leading-signals-papers-2026-10-10.md) 결론: S등급 0편. 근거가 가장 있는 것은 체결 매수·매도 불균형
(Kim & Hansen 2026, B등급 프리프린트: 4~12시간 예측). VPIN·미시구조(Easley 외, A)는 방향이 아니라 변동성·유동성 예측,
펀딩·베이시스는 방향 예측 논문 없음(쏠림 경고 용도). 기존 6지표 투표는 거의 한 요인(ADR-0046)이고 p≥60% 적중률이 49~51%(ADR-0042).

## Decision

새 후보 `FlowVote`(family daytrade, 15m, 롱·숏)를 `DayTradeVote` 옆에 추가한다. 실행 중인 모의투자 전략은 바꾸지 않는다.

- 방향 입력은 하나: `flow = (2·Σ taker_buy − Σ volume) / Σ volume` (최근 W봉), `z` = flow를 최근 960봉 평균·표준편차로 표준화(480봉 = 5일; 960봉이면 워밍업이 잠긴 구간 2022-08~2023-04-06을 읽어 선별이 거부돼 줄였다).
  `z ≥ 1` 롱, `z ≤ −1` 숏, 보유 중 `z`가 0을 넘어 반대로 가면 청산. W = 16(4시간) 또는 48(12시간); 보정 horizon도 W.
- `p_long`은 기존 투표와 같은 ridge-Platt(점수→P(W봉 뒤 수익>0), 실현된 쌍만 사용). 정보가 없으면 0.5 근처 → 위험 1% 바닥(ADR-0063).
- 필터(투표 아님): `vpin_gate` = 봉 시간 기준 VPIN 근사(48봉 평균 |불균형|)가 최근 960봉 상위 10%면 진입 차단(원 논문은 거래량 버킷 기준이라 근사임),
  `funding_gate` = 최근 9회 펀딩 평균이 쏠림(|점수|≥0.5)인 쪽 진입 차단(롱 과밀이면 롱 금지). 두 필터는 함께 켜는 묶음으로만 후보화.
- 손절 2.5ATR(엔진이 1~2%로 제한), 12시간 시간 손절, 변동성 게이트, 위험 엔진은 그대로. 필요한 값(taker 체결량, ATR, 펀딩)이 없으면 진입하지 않는다.
- 후보 4개: {W16, W48} × {필터 없음, 필터 있음}. 임계값·창은 결과를 보기 전에 고정(추가 탐색 없음).
- 데이터: 캔들에 `taker_buy_volume`(없으면 None) 추가. 아카이브(klines 열), WS(`k.V`), REST(열 9)에서 채운다. 공개 Binance만, src는 표준 라이브러리만.
- 근사 한계: Kim & Hansen은 15분 정각 직후 체결 단위(aggTrades)인데 여기서는 15분봉 합계다. 같은 효과를 재현한다는 보장이 없다.

## Consequences

- 선별(ADR-0051)만: 4개가 DSR 시도 수에 더해진다. TEST 구간은 읽지 않고 가설 등록·결선 예산(10-29까지 가득)은 쓰지 않는다.
- 선별 결과는 검증 증거가 아니다. 비용(왕복 0.12~0.20%)과 기준선을 못 넘으면 그대로 기록하고 버린다.
- 호가창·청산 데이터는 과거 구득이 불확실해 제외했다.

- 펀딩 9회 평균과 이후 수익률 상관 -0.005~+0.02.

- 비용·위험 엔진(1~2% 손절, 확신도별 위험) 포함 결과가 네 후보 모두 음수다. 필터(VPIN·펀딩)는 손실을 거의 줄이지 못했다.
- 같은 구간 기존 투표(DayTradeVote) 선별 폴드 평균도 -1%대로 음수(ADR-0052/0053)라 새 후보가 더 낫다고 말할 수 없다.
- 첫 실행(z창 960)은 잠긴 구간을 읽어 거부됐고, 둘째 실행은 부동소수 합계 차이로 무결성 검사에서 4개 모두 탈락해 코드를 고쳤다(수익 수치는 동일). 이 두 실행은 장부에 올리지 않았고 후보 ID는 최종 실행과 같다.

**결론:** 통과 후보 없음. 결선 후보로 올리지 않는다. 모의투자 전략은 그대로(그림자 점수 매기기는 증거가 없어 보류).
