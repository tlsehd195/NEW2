# ADR-0067: 현물 롱 + 선물 숏 캐리 모의 시뮬레이터 (규칙 예외 포함)

**Status:** Accepted (모의 측정 전용, 실거래 경로 없음)
**Date:** 2026-10-10
**Deciders:** account owner ("진행해봐"), Claude Code session

## Context

H-0012(펀딩 부호로 뒤집는 캐리, ADR-0013)는 잦은 전환과 체결비용 때문에 졌다. 한 번 잡고 계속 들고 있는 방식은 `scripts/diagnose_carry_hold.py`(Actions 런 38044574210)에서 비용 후 BTC 연 20.6%, ETH 24.3%(2021-01~2022-08), BTC 10.8%(2023-04~2024-03, 명목 기준)였다. 그 진단에는 청산, 증거금 추가, 자본 비용이 없었다. 사용자가 이어서 진행하라고 했다.

## Decision

1. **규칙 예외:** 이 전략은 며칠~몇 달 보유라 15분/5분 단일 시간봉 규칙(ADR-0030, 0066) 밖이다. 사용자가 "진행해봐"로 모의 시뮬레이션에 한해 허용했다. 기존 15분 투표 모의투자 전략은 건드리지 않는다. 이 예외는 이 시뮬레이터에만 적용되고 다른 다일 전략을 열어주지 않는다.
2. **구현:** `src/cointrader/carry/` (`executor.py`: 두 다리 실행 인터페이스 `CarryExecutor`와 모의 구현 `PaperCarryExecutor`, `runner.py`: 시간봉 단위 규칙과 지표), `scripts/run_carry_paper_sim.py`, `.github/workflows/carry_paper_sim.yml`. 실거래 실행기는 만들지 않았다. 나중에 라이브용 실행기를 같은 인터페이스로 끼울 수 있게만 했다.
3. **모델:** 현물 롱과 무기한 숏을 같은 코인 수로 잡고, 선물 증거금은 명목의 1/레버리지(격리). 펀딩은 정산 시점의 마크가격 명목(가격 변동 반영)으로 증거금 잔고에 들어가거나 빠진다. 양 다리 수수료 0.10%/0.05%(왕복 0.30%, 슬리피지는 설정값, 기본 0). 청산: 매 봉의 고가에서 `configs/margin_policy.json` 등급표(가정, verified=false)의 유지증거금 아래로 내려가면 청산, 증거금 전액 손실, 현물 매도. 증거금 추가: 봉 종가에서 증거금비율이 `레버리지 비율의 50%` 아래면 현물을 팔고 선물을 같은 수량 되사서 비율을 원래대로 되돌린다(닫힌 식, 수수료 지불). 선택 규칙: 최근 21회 정산(7일) 평균 펀딩이 연 0% 미만이면 청산하고 5% 초과면 재진입. 자본: 현물 + 증거금 + 수수료 = 투입금, 차입 없음.
4. **데이터·예산:** 잠금/예약 구간과 겹치면 스크립트가 거부한다(ETH 2023-04~2024-03은 잠겨 있어 실제로 거부됨). 가설 등록, 결선 구간, 30일 예산을 쓰지 않았다. 파라미터(레버리지 1.5/2/3/5, 임계값)는 데이터에 맞춰 고른 값이 아니라 격자 그대로 보고한다.

*가격이 올라 청산될 때까지 남은 여유(선물 명목 대비 %, 봉 고가에서의 최솟값).

- 2021~22(강세장)에서는 BTC 14~18%, ETH 17~22%. 2023~24에서는 BTC 7~9%로 절반 수준이다. 펀딩 수입 자체가 작은 시기이고(연 약 11%), 비용은 투입금의 0.14~0.43%뿐이다.
- 레버리지를 올리면 연수익이 오르는 건 증거금에 묶이는 돈이 줄어서다(투입금 대비 명목 비중이 커진다). 그 대신 청산 여유가 줄어든다. 5배는 BTC 2023~24에서 실제로 청산당해 연 2.2%로 떨어졌고 낙폭 6.3%였다. ETH 5배도 여유가 3.8%(고가 기준 2.3%)까지 내려갔다.
- 펀딩 필터(7일 평균 연 0% 미만이면 이탈)는 항상 보유보다 낮거나 비슷했다. 2021~22는 14.6~19.7%(항상 보유 13.9~21.7%), 2023~24는 6.4~8.6%. 이탈·재진입 수수료가 투입금의 1.5~2.7%(2021~22)로 쌓였다. 2023~24 BTC 5배에서 필터 쪽이 청산을 피한 건 그 시기 포지션 밖이어서이고, 필터가 청산을 막는 장치라는 근거는 아니다.
- 이전 진단(명목 기준 20.6/24.3%)과 숫자가 다른 이유: 이전 것은 진입 시점 명목에 펀딩을 곱했고, 여기서는 가격이 오른 만큼 커진 명목에 곱하며 증거금 추가 때 규모가 줄어든다. 투입금 기준이라 분모도 다르다.

## Consequences

- **한계(숫자에 안 들어간 것):** 세금(한국 2027~), 원화 환산·입출금, 현물 자금의 이자·대출 비용, 거래소 점검·출금 지연, 펀딩이 연속 음수일 때의 슬리피지, 실제 등급표(가정값 사용), 1시간봉 안의 순간 급변(고가로만 근사). 표본은 세 구간뿐이고 2024-03-25 이후는 잠금/예약 때문에 못 봤다. ETH 2023~24는 잠겨 있어 못 쟀다.
- **결론:** 1~3배에서는 청산 없이 7~22%(투입금 기준)가 나왔고 낙폭은 작다. 하지만 시기에 크게 달렸고(BTC 7~9% vs 14~18%), 높은 레버리지는 청산 위험이 실제로 나타났다. 실거래는 바이낸스 계좌가 필요해 사용자가 지금 못 한다. 모의 수치가 실거래로 이어지려면 실제 등급표 확인이 먼저다.
- 후속 후보(사용자 결정 대기): 최근 구간(잠금 해제 후)에서 재측정, 증거금 추가 트리거 값 비교(사전 지정 후), 업비트 현물 + 바이낸스 선물 조합의 원화 환산.
