# ADR-0068: 캐리 원화·세금 반영과 증거금 등급표 스트레스

**Status:** Accepted (모의 측정 전용)
**Date:** 2026-10-10
**Deciders:** account owner ("A B"), Claude Code session

## Context

ADR-0067 후속. 사용자가 (A) 실제 증거금 등급표로 재측정, (B) 원화·세금 반영을 모두 하라고 했다.

## Decision

1. **A는 실제 등급표를 못 구했다.** 바이낸스 도메인은 이 세션에서 열리지 않고(WebFetch ENOTFOUND), 웹 검색에도 표가 나오지 않았으며, `leverageBracket` API는 API 키가 필요한데 사용자는 계정을 만들 수 없다. 그래서 `configs/margin_policy.json`은 `verified=false` 그대로 두고, 대신 **스트레스**를 넣었다: `scripts/run_carry_paper_sim.py --mmr-scale`이 가정 유지증거금률·금액을 0.5/1/2배로 바꾼다. 가정값이 실제와 다르더라도 결론이 뒤집히는지 본다.
2. **B:** `src/cointrader/carry/krw.py`의 `after_tax_view`가 기존 `KrwTaxConfig`(22%, 기본공제 250만원, 2027년 규칙, 미검증)와 `ExitCostConfig`(업비트 매도 0.05%, 바이낸스 출금 1 USDT, 은행 출금 1,000원)를 써서 투입 원화별(1천만/3천만/1억) 세후 연수익을 계산한다. 1년 같은 수익이 나고 연말에 한 번 원화로 뺀다고 가정하고, 환율은 1,400원으로 고정한다. 환율 변동(환차손익)은 넣지 않았다.
3. 사전등록·예산·결선 구간 미사용. 잠금/예약 구간은 스크립트가 계속 거부한다.

## Results (Actions 런 38048118475, ADR-0067과 같은 구간·규칙)

**등급표 스트레스(유지증거금률 2배):** 결론이 바뀌지 않았다. BTC 2023~24 5배는 여전히 청산 1회(고가 기준 여유 -2.5%), 1.5~3배는 청산 없음(3배 여유 8.2%, 기본 8.7%). ETH 2021~22 5배는 청산 없이 버텼지만 고가 기준 여유가 3.8%에서 2.8%로 줄었고, 펀딩 필터 쪽은 1.3%까지 내려갔다. 0.5배(가정보다 느슨한 쪽)에서는 BTC 2023~24 펀딩 필터 5배가 청산 없이 여유 7.7%였다(항상 보유 0.5배 행은 확인하지 않았다). 즉 등급표가 가정과 달라도 5배는 위험하고 3배 이하는 청산 여유가 있다.

**세후 원화(항상 보유, 환율 1,400원 고정, 연 수익 그대로 1년 보유):**

| 구간(레버리지) | 세전 | 1천만원 | 3천만원 | 1억원 |
|---|---|---|---|---|
| BTC 2023~24 2배 | 7.7% | 7.6% | 7.6% | 6.5% |
| BTC 2023~24 3배 | 8.6% | 8.5% | 8.5% | 7.2% |
| ETH 2021~22 2배 | 17.5% | 17.4% | 15.4% | 14.2% |
| ETH 2021~22 3배 | 19.4% | 19.3% | 16.9% | 15.6% |

- 연 수익이 250만원 공제 안에 들어가면 세금은 0이고 출금 비용(약 0.08%)만 든다. 연 수익이 7%대면 약 3천만원까지 세금이 거의 없다. 1억원이면 7.7% → 6.5%, 17.5% → 14.2%로 줄어든다.
- 이 세후 수치는 **환율 변동을 뺀 것**이다. 원화 환산에서는 USDT 환율이 몇 % 움직이는 것이 캐리 수익 전체와 같은 크기일 수 있다. 환율은 이 시뮬레이터에 넣지 않았고, 따라서 원화로 보면 이 수익은 보장되지 않는다.

## Consequences

- 등급표 미검증 상태는 그대로다. 실제 표는 바이낸스 계정/키가 생기거나 사용자가 공식 페이지에서 가져다 줄 때만 확인할 수 있다.
- 한계(ADR-0067과 동일) + 환율 변동 + 세금 기준 불확실(선물 손익 과세 방식 미확정).
- 후속 후보: 업비트 KRW-USDT 과거 환율로 실제 환차손익 넣기(Actions로 이력 수집 필요), 잠금 해제된 최근 구간 재측정.
