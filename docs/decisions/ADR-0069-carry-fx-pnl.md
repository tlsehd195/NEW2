# ADR-0069: 캐리 환차손익 반영과 최근 구간 재측정

**Status:** Accepted (모의 측정 전용)
**Date:** 2026-10-10
**Deciders:** account owner ("C"), Claude Code session

## Context

ADR-0068 후속. 사용자가 업비트 원화-USDT 환율을 넣은 환차손익 반영 재측정(C)을 고르셨다.

## Decision

`scripts/run_carry_paper_sim.py --fx`가 업비트 KRW-USDT 일봉으로 구간의 시작·끝 환율, 환율 변화, 구간 내 최저·최고(시작 대비)를 구하고, 각 결과에 `krw_apr_with_fx_pct`(= 캐리 수익과 환율 변화를 곱해 연환산)를 붙인다. 구간 시작 14일 안에 일봉이 없으면 "환율 없음"으로 표시하고 첫 일봉 날짜를 알려 준다. 가정으로 메우지 않는다. 사전등록·예산·결선 구간 미사용, 잠금/예약 구간은 계속 거부한다.

## Results (Actions 런 38048997949, 38048895186)

1. **업비트 KRW-USDT 일봉은 2024-06-07부터만 있다(855개).** 그래서 ADR-0067/0068의 세 구간(2021~22, 2023~24)은 환율 데이터가 없어 환차손익을 넣을 수 없다. 환율을 다른 데이터로 지어내지 않았다.
2. 환율 데이터가 있고 잠금/예약이 아닌 구간은 **ETH 2025-06-18~2026-08-31 (440일)** 하나뿐이다. BTC 2024-06-18~2025-06-18, 2025-06-18~2026-09-01과 ETH 2024-06-18~2025-06-18은 잠금/예약과 겹쳐 스크립트가 거부했다.
3. 그 구간 결과(수수료·청산·증거금 추가 포함, 청산 0회):

| 방식 | USDT 기준 연수익 | 원화 기준(환차 포함) |
|---|---|---|
| 항상 보유 1.5~5배 | 1.57~1.87% | 0.84~1.13% |
| 펀딩 필터 1.5~5배 | 1.25~1.56% | 0.52~0.83% |

   환율은 1,391원 → 1,379원(-0.9%), 구간 중 시작 대비 최저 -3.7%, 최고 +19.0%였다. 펀딩 수입이 440일 동안 투입금의 3%대(5배 필터 2.75%)에 그쳤다.

## Consequences

- **최근 구간에서는 캐리가 거의 죽었다.** 2021~22 14~22%, 2023~24 7~9%였던 같은 방식이 2025-06~2026-08에는 연 1.6~1.9%(USDT), 원화로 0.8~1.1%다. 자본 비용 가정 연 4%에도 못 미친다. 펀딩 수입이 줄어드는 추세가 보이고, 이 한 구간(ETH)이 앞으로를 대표한다는 보장은 없지만, 가장 최근 데이터라 무시할 수 없다.
- 환율 변동은 이 구간에서 연 -0.6%p 정도였지만 구간 중 +19% 급등이 있었으므로, 원화로 볼 때 환율 위험은 캐리 수익보다 훨씬 크다.
- 결론: 실거래를 못 하는 지금 모의로도, 최근 수익성으로는 캐리를 더 밀 근거가 약하다. BTC 최근 구간은 잠금/예약이라 재측정할 수 없다(예약 해제나 새 구간이 쌓일 때까지).
- 한계: 표본은 자산 1개, 1개 구간. 일봉 환율이라 일중 변동은 없다. 세금·등급표 한계는 ADR-0067/0068과 같다.
