# ADR-0070: 기존 6지표와 겹치지 않는 지표 후보 측정

**Status:** Accepted (측정·선별 완료, 탐색적, 검증 결과 아님)
**Date:** 2026-10-10
**Deciders:** account owner (동동 "겹치지 않는 지표를 더 추가하거나 바꾸면?"), Claude Code session

## Context

15분봉 투표 6지표는 독립 정보 약 1.7~2.4개분(ADR-0046)이고 p≥60% 적중률이 49~51%(ADR-0042), 추적 손절은 더 나빴다(ADR-0052/53),
taker flow·VPIN·펀딩 방향, 급등 후 되돌림, 변동성 구간, 시간대, 펀딩 정산은 이미 비용 미달로 측정했다(ADR-0064/0065). 그래서 이 ADR은 그것들을
다시 하지 않고, 아직 안 본 정보 종류를 한 번에 잰다. 실행 중인 모의투자 전략과 설정은 바꾸지 않는다.

## Decision

결과를 보기 전에 고정한 규칙(창·상수 모두 `features/candidate_indicators.py`에 고정, 결과로 조정하지 않음):

1. 후보 18개: 방향형 9(vwap_dist, skew96, clv16, tod_seasonal, volspike_signed, ac_dir, vr_dir, lead_lag(BTC↔ETH), oi_dir),
   비방향형 9(rv_ratio, vov, squeeze, nr_rank, volspike, ac1, vr, kurt96, oi_chg). 창은 96봉(1일)·480봉(5일).
2. 겹침: 투표에 들어가는 형태의 점수와 기존 6개 점수의 상관(최대 |상관|), 6+1열의 참여비율·엔트로피(ADR-0046 방식). 수익률은 안 읽는다.
3. 예측력(4h=16봉, 12h=48봉, 겹치지 않는 표본, 인과적 expanding z): T1 상관(z, 이후 수익률) / T2 상관(z, |이후 수익률|)(비방향형) /
   T5 상관(투표 점수, 이후 수익률)(비방향형) / T4 추세 추종 우위가 후보 상위·하위 3분위에서 다른가(비방향형). 거래당 평균(|z|≥1, 부호는 투표 규약 고정)을
   왕복 비용 0.12~0.20%와 비교, 표본 전·후반 부호 일치 확인.
4. 다중검정: 모든 T1/T2/T5/T4 p값(BTC·ETH 합산)을 한 가족으로 묶어 Holm·BH를 적용하고 가족 크기 m과 우연 기대 개수를 같이 적는다.
   기존 6지표는 대조군(가족에 넣지 않음).
5. "예측력 있음" 기준(사전 고정): Holm 통과 AND BTC·ETH 같은 부호 AND 전·후반 같은 부호. "비용 통과" 기준: 위에 더해 |거래당 평균| > 0.20%.
6. 선별 변형(투표에 추가/교체)은 **겹침 기준(수익률 안 읽음)** 으로 고른다: 방향형 중 6개와 최대 |상관|이 가장 낮은 후보를 추가, 6개 중 가장 중복인 지표를
   교체. 예측력 상위로 고르면 같은 구간에서 고르고 같은 구간에서 재는 셈이라 별도 변형으로만 두고 표시한다.
7. 조건: BTC/ETH 15분봉, 2023-04-20~2024-03-25(예약된 TEST 이전), 결선·가설 등록 없음(예산 2026-10-29 11:32 KST까지 가득), TEST 미사용.

## Consequences

- 측정은 데이터(data.binance.vision)가 클라우드 프록시에서 막혀 GitHub Actions에서 돌린다.
- 선별 변형이 생기면 DSR 시도 수에 더해진다.

## 사용자 추가 규칙 (2026-10-10)

"보조지표 역할은 겹치면 안 돼". 규칙 6을 대체한다: 선별 패널은 **투표 형태 열끼리 쌍별 |상관| ≤ 0.5가 BTC와 ETH 모두에서** 성립할 때만 만든다
(ETH 0.50은 탈락). 수익률은 읽지 않는다. 이 기준으로 큰 조합 10개는 버렸고, 통과한 패널 P1·P5·P6·P7(각 h16·h48)만 선별했다.
선별 대상 변형: 후보 1개 추가 6개(규칙 6 원안, 겹침 최저) + 역할 구분 패널 8개. 합계 14개가 `configs/strategies.json`에 별도 id로 있다
(실행 중 전략·설정은 불변, 기본 id·파라미터 불변).

## Results

측정: BTC 2023-04-20~2024-03-25, ETH 2024-12-10~2025-12-01(ETH 잠금 구간 회피), lead-lag는 둘 다 2022-01-10~2022-08-10(잠금 밖 유일 구간).

**예측력(다중검정 가족 180개 p값, 우연 기대 9개):** 원시 p<0.05가 34개, Holm 통과 13개, BH 통과 19개. Holm 통과 13개는 전부 T2(|이후 수익률|과의
상관), 즉 변동성 **크기** 예측이고 방향 예측이 아니다: volspike, rv_ratio, nr_rank, squeeze, vov(BTC·ETH 같은 부호). 이는 변동성 군집(이미 알려진 사실)이며
거래할 방향을 주지 않는다. 방향 후보(T1, T5) 중 Holm을 통과한 것은 없고, 거래당 평균은 비용 0.12~0.20%를 넘지 못했다. "예측력 있음" 기준(규칙 5)을
만족한 방향 지표 없음. lead_lag(BTC↔ETH)은 2022년 구간에서만 쟀고 방향 예측으로 살아남지 못했다.

**겹침(투표 형태, 6개 대비 최대 |상관| / 6+1 유효 독립 수):** 후보 대부분은 0.06~0.3으로 겹침이 작다(예: ETH 한 후보는 0.06이고 유효 독립 수가 1.66에서 2.16으로 늘어남).
즉 "겹치지 않는 정보"는 있지만 그 정보가 수익률 방향과 이어지지 않는다.

**선별(BTCUSDT 15분봉 2023-04-25~2024-06-16, 45개 폴드, 평균 폴드 수익률 / DSR, 모두 무결성 통과):**

## Interpretation and caveats

- 지표를 줄이고 역할 구분 열을 넣을수록 평균이 덜 나빠지고, 양수는 P5·P7의 h48 둘뿐이다. 하지만 DSR이 0.12~0.18로 0.95에 한참 못 미치고,
  기본 6개 대비 개선의 상당 부분은 **거래 횟수가 줄어든 효과**(폴드 다수가 거래 0건)로 설명될 수 있다. 수익률 변동도 h48이 크다(한 폴드 +28%).
- 패널·시차 선택은 같은 구간의 예측력 단서를 일부 본 뒤에 했다. 그래서 이 표는 근거가 아니라 **다음에 볼 후보**일 뿐이다.
- 이전 ADR(0064/0065)의 ETH 측정이 잠긴 구간을 읽었을 가능성: 이번에 ETH 잠금(TEST-13/15) 때문에 구간을 2024-12-10 이후로 옮겼다. 그 ADR의 ETH 수치는
  이 규칙으로 다시 확인하지 않았다.
- 결선 시험 없음, TEST 미사용, 가설 등록 없음(예산 2026-10-29 11:32 KST까지 가득). 모의투자 전략·설정 변경 없음.
- 원장 `research/screening.jsonl`의 두 행은 요약본(폴드 수익률·거래 수 생략, 전체 행은 Actions 실행 로그에 있음)이다. 시도 수 계산에는 지장 없다.
