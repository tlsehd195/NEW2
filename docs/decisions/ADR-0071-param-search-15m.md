# ADR-0071: 15분봉 투표 파라미터 탐색 (보유 시간·진입 문턱·손절 폭)

**Status:** Accepted (2026-10-10 동동님 "ㅇㅇ 진행": 워크포워드 선별 도구로 파라미터 탐색)
**Date:** 2026-10-10
**Deciders:** account owner (동동), Claude Code session

## Context

- 지금까지 선별(ADR-0052/53/64)은 정해 둔 후보 몇 개만 시험했다. 신호가 바뀌는 파라미터 세 가지를 본격적으로 본다.
- 선별만 한다: TEST 봉은 읽지 않고, 결선·가설 등록은 2026-10-29까지 막혀 있으며 사람 승인이 필요하다. 모의투자 전략과 라이브 경로는 그대로다.
- 15분봉 한 가지만 쓴다. 다른 세션이 지표 조합(겹치지 않는 조합)을 따로 선별하므로 지표 구성은 건드리지 않는다.

## Decision

1. 기준 `daytrade_indicator_vote_h16_c0.6_v1`(보유 48봉, 문턱 0.6, 손절 2.5 ATR)에서 **한 번에 하나씩** 바꾼 6개를 선별 전용으로 등록한다. 값은 결과를 보기 전에 정했다.
   - 최대 보유: 24봉(6시간), 96봉(24시간)
   - 진입 문턱: 0.55, 0.65
   - 손절 폭: 1.5 ATR, 3.5 ATR
2. 조합 격자(3×3×3)는 만들지 않는다. 시도 수가 늘면 DSR이 벌을 주고 과적합이 늘기 때문이다.
3. `IndicatorVote.strategy_id`에 기본값과 다를 때만 `_s{손절}`, `_m{보유}`가 붙는다. 기존 id는 그대로다.
4. 선별 구간은 이전과 같다(BTCUSDT 15m, 2023-04-20 ~ 2024-06-18, 마지막 20% 예약·미로드). 기준 후보를 같은 실행에 넣어 나란히 비교한다.
5. 모든 실행은 `research/screening.jsonl`에 남아 결선 DSR 시도 수에 더해진다.

## Consequences

- 이 ADR은 파라미터를 바꾸자는 결정이 아니라 탐색이다. 비용(0.12~0.20%)을 넘는 후보가 없으면 결선 후보는 없다.
