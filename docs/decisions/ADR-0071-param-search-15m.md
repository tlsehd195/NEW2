# ADR-0071: 15분봉 투표 파라미터 탐색 (보유 시간·진입 문턱·손절 폭)

**Status:** Accepted (2026-10-10 동동님 "ㅇㅇ 진행": 워크포워드 선별 도구로 파라미터 탐색)
**Date:** 2026-10-10
**Deciders:** account owner (동동), Claude Code session

## Context

- 지금까지 선별(ADR-0052/53/64)은 정해 둔 후보 몇 개만 시험했다. 신호가 바뀌는 파라미터 세 가지를 본격적으로 본다.
- 선별만 한다: TEST 봉은 읽지 않고, 결선·가설 등록은 2026-10-29까지 막혀 있으며 사람 승인이 필요하다. 모의투자 전략과 라이브 경로는 그대로다.
- 15분봉 한 가지만 쓴다. 다른 세션이 지표 조합(겹치지 않는 조합)을 따로 선별하므로 지표 구성은 건드리지 않는다.

## Decision

1. 기준 `daytrade_indicator_vote_h16_c0.6_v1`(보유 48봉, 문턱 0.6, 손절 2.5 ATR)에서 **한 번에 하나씩** 바꾼 6개를 선별 전용으로 등록한다. 값은 결과를 보기 전에 정했다.
   - 최대 보유: 24봉(6시간), 96봉(24시간)
   - 진입 문턱: 0.55, 0.65
   - 손절 폭: 1.5 ATR, 3.5 ATR
2. 조합 격자(3×3×3)는 만들지 않는다. 시도 수가 늘면 DSR이 벌을 주고 과적합이 늘기 때문이다.
3. `IndicatorVote.strategy_id`에 기본값과 다를 때만 `_s{손절}`, `_m{보유}`가 붙는다. 기존 id는 그대로다.
4. 선별 구간은 이전과 같다(BTCUSDT 15m, 2023-04-20 ~ 2024-06-18, 마지막 20% 예약·미로드). 기준 후보를 같은 실행에 넣어 나란히 비교한다.
5. 모든 실행은 `research/screening.jsonl`에 남아 결선 DSR 시도 수에 더해진다.

## Consequences

- 이 ADR은 파라미터를 바꾸자는 결정이 아니라 탐색이다. 비용(0.12~0.20%)을 넘는 후보가 없으면 결선 후보는 없다.
- 결과는 아래에 이어 적는다.

## 선별 결과 (2026-10-10, GitHub Actions run 38060709481, 선별일 뿐 검증 아님)

BTCUSDT 15m, 2023-04-20 ~ 2024-03-25(워크포워드 46폴드), TEST 2024-03-25 ~ 2024-06-18은 이전 예약 그대로(읽지 않음).
PBO 0.07, DSR 시도 수 90. 폴드 평균 수익은 모두 음수다(비용 0.12~0.20% 이전에 이미 손실).

| 후보 | 바꾼 것 | 폴드 평균 | DSR |
|---|---|---|---|
| 기준 h16 c0.6 | 보유 48봉·손절 2.5 | -2.93% | 2e-11 |
| 보유 24봉 | 6시간 | -2.96% | 3e-10 |
| 보유 96봉 | 24시간 | -2.80% | 3e-10 |
| 문턱 0.55 | 거래 많음 | -5.41% | 2e-15 |
| 문턱 0.65 | 거래 적음(빈 폴드 다수) | -1.78% | 1e-13 |
| 손절 1.5 ATR | | -2.93% | 9e-9 |
| 손절 3.5 ATR | | -2.35% | 2e-9 |

- 방향: 문턱을 올리면(거래를 줄이면) 손실이 줄고, 내리면 늘어난다. 손실이 줄어든 것은 거래를 안 해서이지 수익이 생긴 것이 아니다. 보유 시간은 거의 영향이 없다.
- 손절 폭은 진입가의 1~2%로 제한(ADR-0060)되어 있어 1.5/3.5 ATR 차이가 크게 반영되지 않는다.
- 기준 후보 -2.93%는 ADR-0052의 -0.96%와 다르다. 그 사이 위험 크기 규칙이 바뀐 것(ADR-0059~0063, 거래당 위험 1~5%)이 원인으로 보이나 이 실행에서 따로 확인하지는 않았다. 이번 7개끼리의 비교만 유효하다.
- 결론: 비용을 넘는 후보 없음, 결선 후보 없음. 결선·가설 등록은 계속 막혀 있다(2026-10-29, 사용자 승인).

## ETHUSDT 선별 결과 (2026-10-10, Actions run 38068661057, 선별일 뿐 검증 아님)

ETH 2023-04~2024-12는 잠긴 구간(H-0013, H-0015)이라 쓸 수 없어, 잠기지 않은 2024-12-15 ~ 2026-04-04(워크포워드 65폴드, 거래가 없는 폴드 많음)에서 같은 7개를 돌렸다. PBO 0.0, DSR 시도 수 97.

| 후보 | 폴드 평균 | DSR |
|---|---|---|
| 기준 | -1.12% | 1e-4 |
| 보유 24봉 | -1.55% | 6e-15 |
| 보유 96봉 | -1.24% | 9e-10 |
| 문턱 0.55 | -3.41% | 5e-8 |
| 문턱 0.65 | -0.52% (대부분 폴드 무거래) | 2e-3 |
| 손절 1.5 ATR | -1.43% | 5e-5 |
| 손절 3.5 ATR | -1.02% | 2e-5 |

- BTC와 같은 모양이다: 전부 음수, 문턱을 올려 거래를 줄일수록 손실이 줄 뿐 수익은 없다. 보유 시간과 손절 폭은 거의 영향이 없다.
- 이 실행의 TEST 예약(2026-04-04~2026-08-01)은 다른 스레드가 이미 잡은 ETH 예약(2026-04-28~2026-08-31)과 겹쳐 따로 추가하지 않았다. 이 실행은 2026-04-04 이후 봉을 읽지 않았고, 예약 구간은 어느 선별도 읽지 않았다(장부 검사 통과).
- 종합: BTC·ETH 모두 비용을 넘는 후보 없음. 이 세 파라미터를 조정해서는 비용을 넘지 못한다. 결선 후보 없음.
