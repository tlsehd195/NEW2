# ADR-0079: 레짐별 모멘텀/되돌림 전환 투표 (S3, 선별 전용)

**Status:** Accepted (선별 진행 중, 결과는 아래에 이어 적는다)
**Date:** 2026-10-10
**Deciders:** account owner (동동 "S3은 너가 추천하는 방법으로 진행"), Claude Code session

## Context

- 전략 리서치 보고서의 S3: 시장 상태에 따라 추세 추종과 되돌림을 갈아타면 한 가지로 고정한 것보다 낫지 않은가.
- 지금까지: 변동성 구간 필터는 비용 미달(ADR-0065), 지표별 보정 정보 없음(ADR-0072/0074/0075), 파라미터 격자 전부 음수(ADR-0071), 겹치지 않는 지표 추가 방향 예측 없음(ADR-0070).
- 선별만 한다. 결선·가설 등록은 2026-10-29까지 막혀 있고(예산 가득) 사람 승인이 필요하다. 모의투자 전략, `DEFAULT_PANEL`, 라이브 경로는 건드리지 않는다.

## Decision

1. 기존 6지표 투표(기준 `daytrade_indicator_vote_h48_c0.6_v1`)를 그대로 두고, 진입 직전에 `classify_regime`(변경 없음) 결과로 모드를 고른다. 아래 규칙은 결과를 보기 전에 고정했고 결과로 조정하지 않는다.
   - follow: 투표 그대로(모멘텀). fade: 투표의 거울상(P(long)→1−P(long), 롱·숏 동의 수 교환, 되돌림). flat: 신규 진입 없음.

   | 레짐 | s1 | s2 |
   |---|---|---|
   | TREND_UP / TREND_DOWN | follow | follow |
   | RANGE | fade | fade |
   | LOW_VOLATILITY | fade | flat |
   | HIGH_VOLATILITY, UNDEFINED | flat | flat |

2. 변형은 이 2개뿐이다(`regime_switch="s1"|"s2"`, id 접미사 `_rss1`, `_rss2`). 기본값은 꺼짐이라 기존 id·파라미터는 그대로다. 진입 문턱 0.6·동의 0.6·손절·보유 48봉·청산 문턱은 기준과 같다. 전환 후에는 그 레짐의 모드로 청산 신호를 계산하고, flat 레짐에서는 청산 신호를 내지 않는다(손절·시간 손절·거래소 손절이 닫는다).
3. 선별 구간: BTCUSDT 15m 2023-04-25 ~ 2024-06-16(ADR-0070과 같음, 이미 예약된 TEST 2024-03-25 이후는 읽지 않음). ETHUSDT 15m 2024-12-14 ~ 2026-08-31(ETHUSDT 잠금 2024-12-01 이후, ADR-0075와 같은 시작). 기준 후보를 같은 실행에 넣어 나란히 비교한다. 모든 실행은 `research/screening.jsonl`에 남아 DSR 시도 수에 더해진다.
4. 비교 기준: 기준 후보(ADR-0071의 h48 기준 -2.9% 근처)보다 낫고, 왕복 비용 0.12~0.20% 위에서 평균 폴드 수익이 양수이며 BTC·ETH 둘 다 같은 부호일 때만 "단서". 둘 중 하나라도 아니면 결선 후보 없음. 거래 수가 줄어서 덜 잃는 것은 개선으로 치지 않는다(거래 수를 같이 적는다).
5. 거울상(fade) 자체의 효과를 따로 보기 위해, 결과에 BTC·ETH에서 평균 폴드 수익과 거래 수를 레짐별로 쪼개지는 않는다(후보를 늘리는 것이므로). 보고는 후보 단위만 한다.

## Consequences

- 이 ADR은 전략을 바꾸자는 결정이 아니라 측정이다. 결과가 좋아 보여도 결선·등록은 2026-10-29 이후 사람이 결정한다.
- 후보 3개(기준 포함 2개 변형) × 2 시장이 DSR 시도 수에 더해진다.

- 결선·가설 등록·모의투자 전략 변경 없음.
